# Security Policy

## Supported versions

Only the current version gets security fixes: the client served at https://web.areyouok.cyou/k/, built from
`master`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately, through GitHub's
[private vulnerability reporting](https://github.com/morethanwords/tweb/security/advisories/new) or by email to
security@telegram.org.
